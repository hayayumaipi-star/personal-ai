# LifeOS との関係（実測にもとづく現状）

最終更新: 2026-09-19

## 結論：**LifeOS 本体は入れていません。構造だけ借りました。**

本人の判断（2026-09-19・「②で進めて」）。理由は下の「入れなかった理由」。

## 何を借りたか

`danielmiessler/LifeOS`（MIT・TypeScript）を取り寄せて中身を読み、
**ファイルの形だけ**を借りました。コードは1行も使っていません。

| 借りたもの | このリポジトリでの置き場 |
|---|---|
| `USER/TELOS/TELOS.md` の見出し構成（Current State → Ideal State → Mission → Problems → Goals → Challenges → Strategies → Projects → Wisdom） | `lifeos/TELOS.md`（**質問の型だけ**） |
| 「変わらないこと」と「起きたこと」を分ける考え方 | アプリの `profile` と `notes` / `turns`（元からある） |

**`lifeos/IDENTITY.md` と `lifeos/MEMORY.md` は消しました**（2026-09-19）。
理由：中身がその人ひとりのものなので、git に置くと配れない。しかも
`IDENTITY.md` の見出しは `PROFILE_CATS` と、`MEMORY.md` は `notes` / `turns` と
**同じものを2か所に持つ形**だった（決まり7e）。置き場はアプリの中だけにした。

## 入れなかった理由（測った結果）

導入の手前まで実際に進めました。

```
取り寄せ        ✅ 51MB・今日も更新されている
前提            ✅ Ubuntu 24.04 / claude-code 検出 / bun 1.3.11 / git 2.43.0
衝突            ✅ ゼロ（skillCollisions 0）
置く計画        ✅ blockers ゼロ・failures ゼロ
実際に置く      ⛔ ハーネスの安全装置が拒否（第三者コードの実行・環境変更）
```

**そもそも入れても記憶が残らない**、という構造の問題もありました。
LifeOS は `~/.claude` にデータを置きますが、**ここは使われないと消えるコンテナ**です。
だから `USER/` を外へ出す作業がどのみち必要で、それなら最初から外に置くほうが早い。

なお `/root/.claude/LIFEOS` は存在せず、**何も書き込まれていません**。

## いまの仕組み

**git に置くのは「型」だけ。中身はその人の保存先。**（2026-09-19 に変えた。理由は下）

```
lifeos/TELOS.md        質問の型        ← 誰の中身も入っていない
        │  （同じ質問が app/index.html の TELOS_ASKS にある。正はそちら）
        ↓
アプリ「わたしのこと」タブ → まだ聞いていないこと → 「これを話す」
        ↓
本人が会話で答える → ふつうの読み取りが profile / goal にする
        ↓
その人の保存先（db / localStorage）だけに残る
        ↓
依頼文【この人について分かっていること】に載る → 次の会話で使われる
```

### 前は git に中身を書いていた（やめた）

2026-09-19 まで、`lifeos/TELOS.md` に本人の目的・目標・制約を書いていました。
本人の指摘でやめています。

> 「このアプリは将来的に誰でも使えるようなアプリにしたい。それなら自分専用のような
> 仕組みは作るべきではないのではないか、アプリから TELOS を埋めれるような
> 仕組みを作るべきではないのか」

git に書くと ①配っても中身が付いていかない ②リポジトリに生活データを入れない決まりに反する
③アプリの `profile` と**同じものを2か所に持つ**（決まり7e）。三つとも本当だったので、
**質問だけを残し、答えはアプリの中で埋める**形にしました。

### 残っている「その人ひとり専用」の部分

`lifeos_requests` / `lifeos_results` / `lifeos_memory` の3つは、
**Claude Code のセッションから手で読み書きする**前提の仕組みです。
ふつうの利用者はこれを動かせません。**いまは開発者向けの実験としてだけ残しています。**
アプリはこれが無くても全部動きます（依頼文にも見出しが出ません）。
`lifeos_memory` に何か入っている場合、それは**この端末の持ち主が入れたもの**です。

### つながっていないときも動く

`lifeos_memory` が無い／読めないときは、アプリはこれまでどおり動き、
依頼文に余計な見出しも出ません。テスト837件は失敗0のまま。

## まだできていないこと

- **アプリからの発言が自動で `lifeos_requests` に入る**仕組み。いまは手で書いている
- **定時に自分で起きて処理する**仕組み（Routine）。手段はあるが未設定
- **57個のスキル**は使えない（本体を入れていないため）
- **アプリから外部への通信**が可能かは未測定（この構成では不要）

## 決まり

- **git に人物像を書かない。** 置くのは質問の型だけ。答えはその人の保存先へ
- **推測で人物像を作らない**（決まり2）。アプリが持ってよいのは質問文だけで、
  答えの見本や決めつけを**コードに1文字も入れない**
- 質問を足すときは `app/index.html` の `TELOS_ASKS` を直す。`lifeos/TELOS.md` の表は**写し**
