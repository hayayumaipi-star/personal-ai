# TELOS — 質問の型

> 形は LifeOS（danielmiessler/LifeOS）の `USER/TELOS/TELOS.md` から借りています。
> **LifeOS 本体は入れていません**（理由は `README.md`）。

## ここに中身を書かない

前は、このファイルに本人の目的・目標・制約を書いていました。**やめました**（2026-09-19・本人の指摘）。

> 「このアプリは将来的に誰でも使えるようなアプリにしたい。それなら自分専用のような
> 仕組みは作るべきではないのではないか、アプリから TELOS を埋めれるような
> 仕組みを作るべきではないのか」

そのとおりで、**git のファイルに書いた瞬間、そのアプリはその人ひとり専用になります。**
配っても中身は付いていきませんし、リポジトリに生活データを入れない決まりにも反します。

だから **リポジトリに置くのは質問だけ**にして、**答えはその人の保存先**に入れます。
答えを入れる場所は新しく作っていません——アプリに元からある
`profile`（わたしのこと）と `goal`（続けたいこと）を使います。

## 質問と、答えの置き場

アプリ側の一覧は `app/index.html` の `TELOS_ASKS`。**ここと同じものを2か所で持たないこと**
（決まり7e）。この表は読むためのもので、正は `TELOS_ASKS` です。

| TELOS の欄 | アプリでの聞き方 | 答えの置き場 |
|---|---|---|
| Mission / Strategies（目的・やり方） | いま力を入れている仕事や勉強は、どんなことですか。 | `profile` 仕事・勉強 |
| Wisdom（大事にしている考え） | 暮らしのなかで、これだけは譲れないと思っていることはありますか。 | `profile` 大事にしていること |
| Challenges（妨げているもの・体） | 体のことで、予定を組むときに知っておいてほしいことはありますか。 | `profile` 体のこと |
| Current State（いまの自分） | 集中が続きやすい時間帯と、切れやすい時間帯はありますか。 | `profile` 性格・傾向 |
| Challenges（苦手・制約） | 苦手なこと、できれば避けたいことはありますか。 | `profile` 苦手・制約 |
| Ideal State（ありたい暮らし） | 気持ちが軽くなる時間や、好きな過ごし方はありますか。 | `profile` 好み |
| Goals（目標） | いま続けたいこと、近づきたい状態はありますか。 | `goal` |

## 聞き方の決まり

- **本人が実際に言ったことだけを残す。** 推測で人物像を作らない（決まり2）。
- **押しても保存しない。** 「これを話す」はチャットへ移して質問を出すだけで、
  答えるのは本人の言葉。ふつうの読み取りが `profile` / `goal` にする（会話が入口）。
- **毎回は聞かない。** 依頼文で「1回の返事につき1つまで・話の流れが自然に触れたときだけ」と頼む。
- **答えなくてよい。** 空のままでもアプリは全部動く。
- **新しいタブを作らない。** 聞く場所は「わたしのこと」タブの中（タブは4つのまま）。
