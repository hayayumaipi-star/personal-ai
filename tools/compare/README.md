# 前の版と、同じ入力で比べる

CLAUDE.md の「変更するときの決まり」にある**大きく変えたら、変える前の版と同じ入力で比べる**の道具。
2026-09-28 まで作業用の一時フォルダにしか無く、別のセッションでは同じ比べができなかった。

```
python3 tools/compare/run.py                    # いまの app/index.html と HEAD（最後のコミット）を比べる
python3 tools/compare/run.py --old HEAD~3       # 3つ前のコミットと比べる
python3 tools/compare/run.py --only rules       # ふだんの言い方だけ
python3 tools/compare/run.py --old abc1234 --new HEAD   # コミットどうし
```

- **AIは呼ばない**（ルールの読み取りだけ）。お金はかからない。キーも要らない。
- ブラウザは Chromium か Edge（`--chrome` か 環境変数 `CHROME` で場所を渡せる。無ければよくある場所を探す）。
- 結果は**リポジトリの外**（一時フォルダの `hitohi-compare`）に書く。`*.diff` が差の全部。
- 全部で 18 回ブラウザを開く。この環境（Linux・4つ並べて）で数分。

## 比べるもの

| | 入力 | やること |
|---|---|---|
| `rules` | `corpus.json`（866文） | 1文ずつ、5つの時刻（1:30・7:00・10:00・16:58・22:30）に言ったことにして、ルールで読んで入れる。残った項目を1行に |
| `seq` | `seqs.json`（会話128本） | 1発言ずつ `sendTurn` に流す（時計は発言の時刻に止める）。返事と、残った項目 |
| `ai` | `corpus.json` | ルールが読んだ項目を「AIが返しそうな形」に崩して `applyOps` に通す（3つの時刻） |

`ai` の6通り（AIは本物ではなく、形だけまねる）：

- `E` … ルールと同じものをそのまま返す
- `N` … 時刻はあるが日付を空で返す（依頼文どおりの形）
- `A` … 時刻を12時間ずらして返す（午前と午後の取り違え）
- `I` … 時刻の無いものに 10:00 を付け、日付は空（言っていない時刻）
- `D` … 日付の無いものに明日の日付を付ける（言っていない日付）
- `G` … 時刻のある予定を、続けたいこと（goal）として返す

## 読み方

差が出た行を1つずつ、**良くなった／悪くなった／前からの弱点**に分ける。
テストが全部通っても、悪化は比べて初めて見つかる（2026-09-28：「今夜ジョギング」の夜が消えていた・
「それまでに」の締切の印が消えていた——どちらもテストは通っていた）。

`corpus.json` と `seqs.json` に文を足すときは、**本人の生活データを入れない**（作った例文だけ）。
足した回は、足す前の版と足した後の版の両方で流すと、足した文がどう読まれるかも見える。

## 出力の形（`rules`）

```
■ 10:00 明日の午前中に病院 → open event「病院」2026-09-29 時刻未定@morning
■ 10:00 来週の水曜にテスト、それまでに単語100個覚える → open event「テスト」2026-10-07 時刻未定 ｜ open task「単語100個覚える」10/07 23:59まで/day
```

予定は日時（終日・時刻未定・`@時間帯`）、用事は期限（`まで`＝締切・`/day` などの確かさ・所要時間・時間帯・`target`）、
くり返しは `［毎週月］`、午前か午後か聞き返すものは `alt=`、返事で伝えたことは `?` のあと。
