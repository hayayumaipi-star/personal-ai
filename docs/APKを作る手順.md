## 1. 準備（初回だけ・3つ）

### 1-1. Node.js

入っているかどうかは、`APKを作る.cmd` が教えてくれます。
入っていなければ、こう出ます：

```
Node.js が入っていません。
  winget install OpenJS.NodeJS.LTS   または https://nodejs.org の LTS 版
```

- `https://nodejs.org` を開いて、**LTS** と書いてあるほうをダウンロード
- インストーラーは、全部そのまま「次へ」で大丈夫です
- **入れ終わったら、黒い窓を一度閉じてください**（閉じないと、入れたことに気づきません）

### 1-2. Expo の無料アカウント

APKを組み立ててくれるサービスです。**お金はかかりません。**

- `https://expo.dev/signup` で登録（Google のアカウントでも作れます）
- ログインは `APKを作る.cmd` の途中で聞かれるので、先にやらなくても大丈夫です

### 1-3. Anthropic の APIキー（**これが本題**）

APK には claude.ai の窓口がないので、**キーが無いとAIはまったく動きません**
（読み取りも予定づくりもルールだけで動きますが、受け止めの一言や習慣の提案は出ません）。

1. `https://console.anthropic.com` を開いてログイン
   （**claude.ai とは別の登録**です。同じメールアドレスで作れます）
2. **クレジットカードを登録して、残高を入れる**
   - ここは避けて通れません。無料枠はありません
   - 少額（5ドル程度）から入れられます
3. 左のメニュー **API Keys** → **Create Key** → 名前は何でも可（例：`hitohi`）
4. 出てきた `sk-ant-…` で始まる長い文字列を **コピーして、メモ帳に貼っておく**

> ⚠ **キーが画面に出るのは、作った直後の1回だけです。**
> 閉じる前に必ずコピーしてください。無くしたら、作り直せば大丈夫です。

**あわせてやっておくと安心**：同じ画面の **Limits** で月の上限額を決めておく。
もしもの時に青天井になりません。

## 2. APK を作る

### 場所

```
C:\Users\zaoji\personal-ai\mobile\APKを作る.cmd
```

エクスプローラーのアドレス欄に `C:\Users\zaoji\personal-ai\mobile` を貼って Enter すると、
そのフォルダが直接開きます。

> 同じフォルダの **`スマホで試す.cmd`** ではありません。あれはその場だけ試すもので、
> アプリは更新されません。

### 2-1. 1回目（すぐ止まります）

`APKを作る.cmd` をダブルクリック。黒い窓が開いて、こう出て**止まります**：

```
作り方そのものが新しくなりました。
  いま動いているのは古い手順なので、ここで止めます。
  もう一度 APKを作る.cmd を実行してください（次は新しい手順で進みます）。
```

**これは正常です。** 何か押して窓を閉じてください。

> **なぜ2回必要なのか**
> PowerShell は、始めにファイルを全部読んでから動きます。
> このファイルは最初に「最新に更新」をしますが、そこで自分自身が新しくなっても、
> **その回に動いているのは古いほう**です。気づかずに進むと、
> 「聞かれるはずのAPIキーを聞かれない」まま10〜20分かけて作ってしまうので、
> **わざと止めています。**

> **止まらずに先へ進んでしまったら**
> もしこの文が出ず、`APIキー:` も聞かれないまま `Expo にログイン…` まで進んだら、
> **窓を閉じてください**（組み立てが始まる前に）。そして 2-2 へ進みます。

### 2-2. 2回目（本番）

もう一度 `APKを作る.cmd` をダブルクリック。今度は最後まで進みます。
画面に出るものと、やることはこうです：

```
AI秘書 — APK を作る

Node.js v22.x.x                          ← 出ていればOK
最新に更新しています...
Already up to date.                       ← ここで赤が出たら「3. うまくいかないとき」へ

初回の準備をしています（数分かかります）… ← 初回だけ。数分待つ

APIキーを焼き込みますか？
  貼り付けて Enter … このAPKの中でAIが使えるようになります。
  何も入れずに Enter … キー無しで作ります（AIは動かず、ルールだけで動きます）。
  ※ このAPKを人に渡すと、キーも一緒に渡ります。
  APIキー: ■                              ← ★ここでキーを貼って Enter
```

**キーを貼る方法**：メモ帳でコピー → 黒い窓の上で**右クリック**（それが貼り付けです）→ Enter。
貼った文字はそのまま見えます。

続けて、**どこのAIのキーかを聞かれます**：

```
  どこのAIのキーですか？
    1 … Claude（Anthropic）— console.anthropic.com で作ったもの
    2 … Gemini（Google）— aistudio.google.com で作ったもの
    そのまま Enter … Claude（Anthropic）（キーの形から推測）
  1 か 2: ■                               ← ★ここで 1 か 2 を打って Enter
```

**ここは必ず自分で選んでください。**推測は外れます——実機で、Gemini のキーが
Claude として焼き込まれ、AIが全部断られました。
**アプリの画面から入れ替える道はありません**（設定タブのAIの欄は外しました）ので、
間違えると作り直すまで直せません。

うまくいくと、すぐ下にこう出ます：

```
  保存しました（mobile\secret.json・Claude（Anthropic））。次からは聞きません。
  違っていたら、そのファイルを消してもう一度実行してください。
写しました: app/index.html → mobile/app-html.js (313,186文字)
APIキーを焼き込みました: claude / ****1234   ← ★末尾4文字が自分のキーと合っているか確認
```

続いて Expo です：

```
Expo にログインしているか確かめます…
```

- ログインしていなければ、ここで**ユーザー名とパスワードを聞かれます**（窓の中で入力）
- Google で登録した人はパスワードが無いので、**ブラウザ側で入ってください**

そのあと、組み立てが始まります。聞かれたら答えてください：

| 聞かれること | 答え |
|---|---|
| `Create a project?` | **Y** |
| `Generate a new Android Keystore?` | **Y**（署名の鍵。Expo が預かります） |

**ここから10〜20分。窓は閉じないでください。**

### 2-3. スマホに入れる

終わると、**ダウンロードURLとQRコード**が出ます。

1. その **QR を、スマホのふつうのカメラで読む**（Expo Go ではありません）
2. ダウンロードが終わったらタップ
3. 「提供元不明のアプリ」の許可を聞かれたら、**許可する**
4. インストール

**前のアプリに上書きされます。記録は消えません。**

## 3. 入ったか確かめる

アプリを開いて、**チャットタブ**で一言打ってください（例：`明日10時から会議`）。

**受け止めの一言（「明日は会議なんですね」のような文）が返ってくれば成功**です。
AIが動いていないと、この一言が出ません（予定そのものは、AIが無くても入ります）。

> **設定タブにAIの欄はありません。** 2026-09-21 に外しました。
> キーを貼る欄も、つながるか試すボタンも、もうありません——
> **入口は焼き込みだけ**なので、確かめる場所はチャットです。

**うまくいかないときは、その吹き出しに理由が出ます。**
`Claude 401：…` `Gemini 400：…` のように、相手が返した理由がそのまま載るので、
**その文をそのまま貼って相談してください。**

## 4. うまくいかないとき

| 画面に出ること | 何が起きたか | どうするか |
|---|---|---|
| `Node.js が入っていません` | 1-1 がまだ | Node.js を入れて、窓を閉じてからやり直す |
| **`最新に更新できませんでした`**（赤） | ネットが切れている／手元のファイルを触った | `y` 以外を押してやめる。**出ている英語をそのまま貼って相談** |
| `作り方そのものが新しくなりました` | 正常（2-1） | もう一度実行する |
| `username, email, or password was incorrect` | Expo のログイン | 窓で `npx eas-cli@latest login`。Google 登録ならブラウザ側で |
| `Cannot find module './app-html'` | 写しが上がらなかった | この行をそのまま貼って相談（直し方は分かっています） |
| キーを貼ったのに `****` が自分のキーと違う | 貼り間違い | `mobile\secret.json` を消して、もう一度実行 |
| チャットで受け止めの一言が出ない | 古いAPKのまま／キー無しで作った | `mobile\secret.json` があるか見て、もう一度作る |
| 吹き出しに `Claude 401` / `Gemini 400` | キーが違う／提供元を取り違えた | `mobile\secret.json` を消して、もう一度実行（**提供元を聞かれるので正しく選ぶ**） |
| 吹き出しに `credit balance` | 残高が入っていない | 提供元の管理画面で残高を入れる |
| 吹き出しに `model` を含む文 | モデル名が合わなくなった | `mobile\secret.json` の `model` に新しい名前を書いて、もう一度作る |
| 吹き出しに **「混み合っている」**（`503`） | 提供元が混んでいるだけ | **本人のせいではない。** 少し待ってもう一度話しかける（アプリが1回は自動で入れ直します） |
| 夕方から急にAIが返らない（`429` / `RESOURCE_EXHAUSTED`） | **その日の回数を使い切った** | 下の「1日に使える回数」を読む |
| 赤い字が出た（上に無いもの） | — | **その画面をそのまま貼って相談。推測で触らない** |

## 4b. 1日に使える回数（Gemini の無料枠）

**このアプリは、1回話しかけるたびにAIを2回呼びます**（受け止めの一言＋読み取り）。
だから「1日に何回まで」がそのまま「1日に何回話しかけられるか」の半分になります。

| モデル | 1日の上限 | 話しかけられる回数 |
|---|---|---|
| `gemini-3.5-flash`（無印） | 20回 | **1日10回で止まる** |
| **`gemini-3.5-flash-lite`** | **500回** | **1日250回** |

**いまの既定は `gemini-3.5-flash-lite`** です。`mobile\secret.json` の `model` が
空っぽなら、これが使われます。無印に戻すと、その日の昼には止まります。

いま何回使ったかは、`https://aistudio.google.com` の使用状況の画面で見られます
（`RPD` の欄。赤くなっていたら使い切っています）。

## 6. 知っておくこと（短く）

- **このAPKを人に渡さないでください。** APK は zip なので、受け取った人は中の文字列を
  読めます。つまり**キーも一緒に渡ります**。人に渡すときは `secret.json` を消してから
  作り直してください。
- **EAS の組み立てはクラウドで動きます。** キーを含んだ一式が Expo のサーバへ上がります。
- **キーが漏れたと思ったら**、Anthropic の画面でそのキーを無効にして、
  新しいキーで作り直すのがいちばん早いです。
- `secret.json` は **git に入りません**（`.gitignore` 済み）。`app/index.html` に
  キーを書かないでください——あれは git にも、共有中の Artifact にも載ります。

## 7. この手順のどこまで確かめてあるか（2026-09-21）

**確かめた**（Linux 上に PowerShell 7 を入れて、偽の `git`/`npm`/`npx` を置いて通しで実行）：

- キーを貼る → `secret.json` が書かれ → 写しに焼き込まれ → 組み立てまで到達
- 2回目は聞かれず、キーはそのまま焼き込まれる
- 何も入れずに Enter → ファイルを作らず、キー無しで進む
- `git pull` 失敗 → 赤で出して聞き、`n` でやめる（組み立てを呼ばない）
- 台本が更新された → 作らずに止まり「もう一度」と言う（組み立てを呼ばない）

**確かめていない**：

- **Windows PowerShell 5.1 での実行**（走らせたのは PowerShell 7）。
  使っているのは 5.1 にもあるものだけに絞ってあるが、同じではない。
- **実際の EAS 組み立てと、スマホへのインストール**（本人の Expo アカウントが要る）。
- **通知の「完了」ボタン**（2026-09-24 に足した）。通知に「完了」が出ること、
  押すとアプリが開いてその予定が終わりになること、どちらも**実機では確かめていない**。
  作り直したら、まず予定を1つ入れて、通知が鳴るのを待って押してみてください。
  うまくいかないときは、何が出たかをそのまま知らせてください。
