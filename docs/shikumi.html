How it works

一日の下書きの仕組み

あなたが整理せずに話す。アプリは言葉をそのまま保存してから意味を読み取り、 記録を更新し、予定を計算し直して、短く返す。
——この一往復が、全部です。

画面は3つ（話す・今日・わたしのこと）＋設定。覚えることはありません。

Pipeline

話しかけてから、返事が出るまで

6つの段を順に通ります。大事なのは 2段目——意味を読み取る前に、言葉をそのまま保存しているところです。

  1. あなたが話す予定も気分も思いつきも、混ぜたままで大丈夫です。
  2. 原文をそのまま保存「午後５時」の全角も、言い間違いも、いじりません。あとで「根拠」として戻れる場所になります。
  3. 意味を読み取る文を1つずつ見て、種類を決めます。ふだんはルール。設定でAIをオンにすると、言い直しや完了の判断もできるようになります。
  4. 確かめてから適用存在しない用事、範囲外の数字、おかしい日付は捨てます。すでにあるものと同じなら作りません。
  5. 予定を計算し直す記録が変わったので、その日の案を作り直します。ここは全部コードの計算です。
  6. 短く返す変えたことを一言、必要なら次の一つ。予定表は大きく変わったときだけ出します。
Memory

何を覚えているか

発言から作られるものは、10種類に分かれています。全部をタスクにはしません。

原文話した言葉そのもの。すべての根拠
タスクやると決めたこと
予定時刻の決まった、動かさないもの
目標日付のない、続けたいこと
体調本人の言葉のまま。点数は作らない
気になっていること迷い・いつか。予定に入れない
メモあとで見返したいこと
こうしてほしい出し方の希望。この日だけ／ずっと
わたしのこと変わらない性質・好み・制約
資料自分で渡した文章そのもの
「いまの状態」は保存していません。 エネルギー62点、といった数字は作りません。その日の案は、見るたびに記録から計算し直します。 保存すると、古い状態が「現在の事実」として残り続けてしまうからです。
Planning

予定はこう組まれる

動かせないものを先に確保し、残った隙間にだけ作業を置きます。空いた時間を全部は埋めません。

  • 締切と、いつ手を付けたいかは別物。「明日までの資料を、できれば今日の午前に」なら、締切は明日のまま、作業は今日の午前に置きます。
  • 移動と準備も動かさない枠。「14時開始、移動40分」と言えば、13:20〜14:00 を移動として確保します。
  • 仮置きは仮置きと書く。時間を言っていなければ30分と仮に置き、「所要時間が書かれていないので30分と仮置きしました」と理由に出します。
  • 続けて90分たったら休憩を挟みます。これはアプリが入れたものだと明記します。
  • 「今日は詰めないで」はその日だけ。「しばらくそうして」ならずっと。一日の気分が永久のルールにならないようにしています。
Division of labour

AIはどこまでやるか

はっきり線を引いてあります。時刻と予定表はコードが作り、AIは文章だけ書きます。

AIをオンにすると

「15時じゃなくて14時」の言い直し、「できた」の完了判定ができるようになります。費用はかかりません（あなたのClaudeの枠を使います）。返事まで数十秒かかります。

AIをオフにすると

何も送信しません。追加・計画・訂正・再計画は全部できます。ただし言い直しと完了の自動判定はできません。そのときは黙って無視せず、「ボタンから直して」と返します。

Foundation

混ぜないと決めた4つの層

この区別が崩れると、AIの推測があなたの決定として残り、古い状態が現在の事実になります。設計の芯です。

層中身
原文あなたが言った言葉そのもの編集しない。すべての項目がここを指している
読み取ったもの原文から作られた項目必ず「どの発言から」「どの部分から」を持つ
確からしさ読み取ったまま／AIが読み取ったまま／本人が訂正各項目に印が出る。これが消えると推測と決定の区別がつかない
いまの状態保存しない見るたびに計算し直す
Guarantees

壊れないようにしてあること

話した言葉は消えない

AIを呼ぶ前に原文を保存します。AIが落ちても、混んでいても、拒否されても残ります。送信欄は送った瞬間に空になり、処理に失敗したときだけ書き戻します。

同じことを二重に作らない

同じ用事は、完了済み・取り消し済みも含めて突き合わせます。だから終わったタスクが再び提案されることはありません。

訂正が最新

直した内容が以後の提案に反映されます。元の読み取り結果は履歴に残り、いつ何を直したか追えます。

黙って失敗しない

ボタンが効かなかったときは必ず画面に理由を出します。「記録した」「完了にした」は、実際に保存が成功したときだけ言います。

根拠にいつでも戻れる

どの項目からも「根拠」を開けば、元の発言のどこから来たかが光ります。日時とタイムゾーンも一緒に出ます。

勝手に確定しない

曜日まで言っていない「来週」は期限にしません。「期限があいまい」と表示して、あなたが決めるまで待ちます。

これらは文章の約束ではなく、203件の自動テストで毎回確かめています。 うち50件は、朝から夜までの会話を1発言ずつ流して、返答・保存内容・予定案・次の一手を検証するものです。
Not yet

まだできないこと

正直に書いておきます。

  • 閉じている間は何も動きません。開いたときだけ動くページです。通知も、朝の自動連絡もありません。
  • カレンダー連携はありません。アプリの中の予定案と、実際のカレンダーは別物です。手入力で試せます。
  • 音声認識は入っていません。スマホのキーボードのマイクボタンを使ってください。
  • 健康データ・栄養・買い物リストは未実装です。体調は、あなたが言ったことを引用して残すだけです。
  • 行動の自動取得はしていません。パソコンやスマホの操作は一切見ていません。
