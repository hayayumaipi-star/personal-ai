# はじめかた（初心者向け）

## 1. 開く

スマホでもPCでも、このURLを開くだけです。インストールは要りません。

```
https://claude.ai/code/artifact/8a5f7690-306a-4941-8b7d-bb595c2fab88
```

- あなたのClaudeアカウントでログインした状態で開いてください。
- **このページを共有している間は、記録も共有されます。**
  記録は**共有の場所**に入っているので、リンクを開いた人には
  **ここにある予定・会話・体調がそのまま見えます**
  （2026-09-13 に別の人に開いてもらって確かめました。相手の画面に、
  こちらが入れた記録がそのまま出ました）。
  2026-09-12 に「記録は人ごとに分かれる」と書いたのは読み違いでした。
  そのとき相手の画面が空だったのは、**その人に保存先が渡らなかったから**です。
- **いまは開発中なので、仲間に見せるために共有したままにしています**（2026-09-13・本人の判断）。
  そのぶん、**見られて困ることは入れないでください。**
  本当の予定として使い始めるときは、先に共有を切ってください。
- **リンクから開いた画面では、記録が保存されません**（2026-09-13 に確認）。
  開いた直後は「保存先に接続済み」と出ますが、**話しかけた瞬間に「この端末のみ」に変わります**。
  読むことはできても、**書き込みだけ拒まれる**ためです。AIも使えず、ルールだけの読み取りになります。
  壊れているのではありません。**ふだんは claude.ai のアーティファクト一覧から開いてください。**
  （リンクから開いて話した内容は、その端末の中には残っています。消えてはいません。）
- 人に**その人自身の秘書**として使ってもらうなら `docs/友達に渡す.md` を見てください
  （リンクではなくファイルを渡すやり方です。データもAIの枠も完全に分かれます）。
- Androidのホーム画面に置くと、アプリのように使えます：
  Chromeでページを開く → 右上の「⋮」→「ホーム画面に追加」

## 2. 最初にやること（3分）

開くと **「チャット」** タブになっています。**整理せずに、そのまま話しかけてください。**

1. **「例を入れてみる」** を押して、そのまま送ってみてください（右の↑ボタン）。
2. 返事の下に、**「変えたこと」** と **その時点の予定案** が出ます。
   時刻はすべてアプリが計算しています。AIに時刻は書かせていません。
   **ここが確認の場所です。** 読み取りが違っていたら、そのまま言い直してください。
   あとで別の画面で確認する手間はありません。
3. 続けて話しかけます。同じ会話の中で言い直して構いません。
   > 「資料、思ったより時間かかってる。あと1時間は必要そう。」
   > 「明日の予定、15時じゃなくて14時だった。移動に40分かかる。」
   > 「資料できた。送るのも終わった。」
   > 「次にやることが一つ分かるくらいの方が楽だから、そういう出し方にして。」
4. 自分の発言の下の **「原文」** を押すと、その一言から何が作られたかを確認して訂正できます。
5. 下のタブで **「スケジュール」** を開きます。上から順に：
   - **今日の案** … 濃い色＝固定の予定（動かさない）／点線＝動かせる作業枠。移動・準備・休憩・予備も出ます。いま進行中の枠は枠線が光ります。
   - **この日にあること（時刻は未定）** … 日付だけ分かっている予定。
   - **この日にやること** … その日が期限なのに、**時刻を言っていない**作業。
     予定表には置きません（こちらが時刻を決めてしまうため）。
     「午前中に」「14時から」のように言えば、上の予定表に入ります。
   - 下の折りたたみ … **この先の予定とタスク** ／ **この日の記録（体調・振り返り）**。
     間違えて完了や取り消しを押したときは、振り返りから**戻せます**。
6. ページを閉じて開き直しても、会話も記録も訂正も残っています。

タブは **チャット / スケジュール / わたしのこと / 設定** の4つです。

## 2.5 「わたしのこと」タブ

**ずっと変わらない、あなたについての情報**が集まる場所です。予定づくりと返事のときに毎回参照されます。
（その日の体調や気分はここには入りません。あれは「スケジュール」タブに、その日の話として残ります。）

2つの欄があります。

**① 自分について渡す** — 自己紹介、仕事や研究の背景、価値観、苦手なこと、昔の日記。
貼り付けるか、テキストファイルを選んで「読み取って足す」。
**資料そのものが残る**ので、あとから読み返せますし、「読み取ったものを見る」でそこから何が拾われたか確認できます。

**② 会話から集まったこと** — 話しているうちに出てきた、あなたについての情報。
「自分は昔から朝が苦手で」のような言い方をすると、ここに貯まります。
「今日は疲れた」は入りません（その日の話なので）。

どちらも**未確認から始まります**。合っていないものは「訂正」か「取り消す」で直してください。

AIに送られるのは、**一覧にある短い文だけ**です。資料の全文は毎回は送りません（長すぎるため、読み取りのときだけ）。
資料が長いときは何回に分けて送るか・何分かかるかを先に表示し、あなたが押したときだけ送ります。
**上限（6万文字）までは全部読みます。**

## 3. 自分のことで使う

スマホのキーボードの **マイクボタン** を押して、思いついたまま話してください。
（音声認識はスマホの標準機能を使います。このアプリ側の音声機能はまだありません）

> 「おはよう。昨日あんまり寝てない。今日は詰めすぎないで。あと、明日までに資料を送らないと。1時間くらいかな。」

各項目には、どこから来た情報かの印が付いています。
**「読み取ったまま」**＝あなたの言葉から読み取っただけで、まだ触っていないもの。
**「本人が訂正」**＝あなたが直したもの。この2つは混ざりません。

- 「今日」「明日」「来週」は、**話した日時**を基準に計算されます。
- **「明日1時から2時まで」は 13時〜14時**として読みます（1時〜5時は午後）。
  深夜のつもりだったときは、項目に出る「**01:00にする**」を押してください。
  「明日9時」のように午前としか読めないものは、そのまま午前です。
- 「来週」のように曜日まで言っていないものは、**期限として確定させません**（「期限があいまい」と表示されます）。
- 体調について話したことは、**そのまま引用**されるだけです。点数も診断も作りません。

### テキストファイルから入れる
「チャット」タブ右上の **「…」** → `.txt` ファイルを選ぶ → 送信。

### 予定表に入れたいとき、入れたくないとき

**時刻を言っていない作業は、予定表に置きません。**「この日にやること」に貯まります。
こちらが勝手に時刻を決めないためです。

| 言い方 | どうなる |
|---|---|
| 明日、資料を作る。2時間。 | **「この日にやること」に貯まるだけ** |
| 明日の**午前中に**資料を作る。2時間。 | 明日の予定表の午前に入る |
| 明日**14時から**資料を作る。2時間。 | 明日の予定表の **14:00–16:00** に入る |

言った時刻が別の予定で埋まっていたら、**勝手にずらさずに**「そこは埋まっています」と出します。
「午前中に」と言って午前が埋まっていたときも、夜に動かしたりはしません。

**「6時から9時の間に30分勉強する」**のように言えば、3時間の予定にはせず、
**その中のどこかに30分だけ**置きます。

### 終わりの時刻を言っていない予定

「12時半からご飯食べに行く」のように終わりを言っていないときは、**1時間で仮置き**します
（「（仮）」と出ます）。

そのあとで「1時から2時まで勉強する」と言うと、**仮置きのほうが短くなります**（12:30–13:00）。
あなたが言った時刻のほうが正しいからです。**始まりは動かしません。**
短くしすぎると10分を切ってしまうときは縮めず、「予定が重なっています」と知らせます。
どちらも終わりを言っているときも、勝手には縮めません。

### くり返しの予定
「**毎週月曜10時からゼミ**」「**毎月1日に家賃を払う**」「**毎日7時に起きる**」のように言うと、
**その曜日・その日に毎回出ます**（毎日／平日／毎週／毎週◯曜／毎月◯日／隔週）。
1日ぶんだけ終わらせたいときは「完了」、その日だけ外したいときは「**この日はやらない**」。
どちらも**次の回は残ります**。

### 何日も続く予定
「**明日から3日間、出張します**」「**14日から16日まで旅行**」で、その全部の日に出ます。
時刻を言っていなければ「終日」として、**作業の時間はふさぎません**。
ふさぎたいときは「その日は予定を入れないで」と言ってください。

### 予定が重なったら
同じ時間に2つ入ると、予定表の下に「**予定が重なっています**」と出ます。
どちらを動かすかはこちらでは決めません。

### 予定を手で入れる
「スケジュール」タブの **「＋ 自分で足す」**。日付バーの「**日付**」で、離れた日にも飛べます。

### カレンダーから取り込む（.ics）
「設定」タブの **「カレンダーを読み込む（.ics）」**。
Googleカレンダーなどから書き出した `.ics` ファイルを選ぶだけです。
**認証も、外部への送信もありません**（ファイルをこの端末で読むだけ）。
くり返しの予定は、最初の1回だけ入ります。
逆に「**カレンダーに出す（.ics）**」で、この先の予定を書き出せます。

## 4. AIのオン・オフ（無料・既定はオン）

「設定」タブの **「話しかけたときにAIへ送る」** で切り替えます。

**オンのとき**：話した内容と、いま開いている用事の一覧が、あなたのClaudeアカウント経由でClaudeに送られます。
「15時じゃなくて14時」のような**言い直し**や、「できた」の**完了判定**ができるようになります。

返事は**二段構え**です。まず速いAIが1〜2秒で受け止めの一言を返し、そのあいだに丁寧なAIが裏で読み取って、
終わったら静かに反映します（「読み取っています…」と出ます）。
1回の発言につきClaudeを**2回**呼びますが、**どちらも追加の支払いは不要**です。

**オフのとき**：何も送信しません。ルールだけで動きます。
**追加・計画・訂正・再計画は全部できます。** ただし言い直しと完了の自動判定はできないので、
そういう発言をすると「AIをオンにするか、ボタンから直してください」と返します。

- どちらでも **費用はかかりません**（別途のAPI契約は不要です）。
- 初回は「このページがClaudeを使ってよいか」の確認が出ます。
- **AIが失敗しても、話した内容と既存の記録は必ず残ります。**

## 5. 設定

「設定」タブで変えられます。

| 項目 | 既定値 | 意味 |
|---|---|---|
| タイムゾーン | Asia/Tokyo | 「今日」「明日」の基準 |
| 所要時間の仮置き | 30分 | 時間が書かれていないときの仮の値（画面にも「仮置き」と表示されます） |
| 休憩を挟む間隔 | 90分 | 続けて作業した時間がこれを超えたら、10分の休憩を自動で入れます |
| AIへ送る | オン | 上の4を参照 |

話しかけて伝えた要望（「詰めすぎないで」「次の一手だけ見せて」「夜は作業しない」）は、
「わたしのこと」タブの **「こうしてほしい、と言ったこと」** に残ります。
やめたいときは、そこの「取り消す」を押してください。
目標・気になっていること・あとで見返すメモも、同じタブにまとまっています。

**「書き出す（JSON）」** で、全データを手元に保存できます。定期的に取っておくことをおすすめします。
**「読み込む（JSON）」** で、その控えを戻せます。**いまの記録は消しません**（同じものは足しません）。

**「古い記録を整理する」** は、**終わった・取り消した項目と、その原文・会話だけ**を消します。
やりかけのものは、どれだけ古くても残ります。

**「記録をさがす」** に言葉を入れると、原文と項目をまとめて探せます。

**「保存されている原文」** は、あなたが話した言葉そのものです。ふだん触る必要はありません。
特定の発言をなかったことにしたいときだけ、ここから消せます（そこから作られた項目は残ります）。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 右上が「この端末のみ」になっている | **リンクから開いていませんか。** リンク経由だと書き込みが拒まれます（上の「1. 開く」を参照）。アーティファクト一覧から開き直してください。それ以外なら、claude.ai にログインしているか確認を。どちらでも入力は端末に残ります |
| 途中で「この端末のみ」に変わった | 保存先に書き込めなくなっています。**理由は「設定」タブの「最後に起きた不具合」に出ます**。その文をそのまま伝えてください |
| 言い直したのに反映されない | 設定でAIがオフになっていませんか。オフのときは言い直しを自動で反映できません |
| 読み取れない用件がある | **1行に1つの用件**にすると精度が上がります。改行で区切ってください |
| 日付がおかしい | 「今日」「明日」は**話した日時**が基準です。前の日のことを今日話すとずれます |
| 開きっぱなしで日付が変わった | 今日を見ていれば**自動で新しい今日に切り替わります**（前の日を見ているときは動きません） |
| 夜中や早朝にも予定が入る | 一日じゅう使える前提になっています。チャットで「夜は予定を入れないで」と言えば止まります |
| 予定が詰め込まれすぎる | チャットで「詰めすぎないで」と言ってください。「わたしのこと」タブに残り、以後ずっと効きます |
| AIが「許可されていません」と出る | Claudeの利用許可を断った状態です。ページを開き直すと再度聞かれます。断ったままでも追加・計画・訂正は動きます |
| 返事が遅い | AIオンのときは数十秒かかることがあります。急ぐときは設定でオフにすると即座に返ります。**90秒返ってこなければ自動でルールに切り替わります** |
| 右上が「オフライン」 | ネットが切れています。話した内容は**この端末に残り**、つながると保存先にも書き込まれます |
| 長い文章を貼ったら止められた | 1回の発言は2万文字までです。長い文章は「わたしのこと」タブの**資料**として入れてください（全文が残ります）|
| スマホとPCで同時に開いている | **同じ日の会話も混ぜて保存します**。ただし片方の画面は自動では更新されないので、開き直してください |
| タイムゾーンを変えたら | 保存済みの予定の日付も**自動で引き直します**（何件直したか出ます）|
