# 人に渡す

渡し方は**2つ**あります。**どちらを使うかで、見える記録が変わります。**

| | 渡すもの | 記録 | 用途 |
|---|---|---|---|
| **A. ファイルを渡す** | `app/index.html` | **完全に分かれる** | 相手にも「自分の秘書」を持ってほしいとき |
| **B. リンクを共有する** | このページのURL | **あなたの記録がそのまま見える** | 開発中に、仲間と同じ画面を見たいとき |

**いまは B で運用しています**（2026-09-13・本人の判断）。
仲間にアプリを見てもらうために共有したままにしていて、
そのぶん **見られて困ることは入れない**ことにしています。
本当の予定として使い始めるときに、共有を切ります。

## まず事実（AもBもこれが前提）

記録は `notes/` `items/` `turns/` `docs/` という **共有の場所** に入っています。
保存先の仕様には、こう書かれています。

> 既定では、**どの閲覧者も共有文書を読み書きする**。

**2026-09-13 に実際に確かめました。** 中身が空の検査ページを作り、こちらから記録を1件入れて、
別の人にリンクを開いてもらったところ、**相手の画面にこちらの記録がそのまま出ました。**

つまり **リンクを渡した相手には、あなたの予定・会話・体調が見えます。**
隠せるわけではないので、**共有するなら「入れない」で守る**しかありません。

2026-09-12 に「記録は人ごとに分かれる」と書いたのは**読み違いでした**。
そのとき相手の画面が空だったのは、保存先が渡らず localStorage だけで動いていたからです。
**空の画面は「分かれている証拠」ではありません。**

以前ここに「`db` を宣言したページは仕様上、公開共有できない」と書いていましたが、
**これは間違いでした**（2026-09-13 に取り消し）。検査ページは公開のまま共有でき、
別の人が開いて中身を読めました。**仕様の文言と実機が食い違ったら、実機が正しい。**

## B. リンクを共有する（開発中の、いまのやり方）

- 相手には **あなたの記録がそのまま見えます**。見せたくないものを入れないでください。
- 相手が**書き込めるか**は未確認です（2026-09-13 時点。検査のとき相手がボタンを押さなかったため）。
  **書けるつもりで扱ってください**——仕様の文面は読み書きの両方を共有すると書いています。
- 相手が使うAIは**相手のClaudeの枠**です。あなたの枠は減りません。
- **共有をやめるときは、アーティファクトの共有設定を切ります。** 記録はあなたのものとして残ります。
- 相手に「自分の予定を入れて使ってみて」と頼むのは B では**やめてください**。
  あなたの予定表に相手の予定が混ざります。それは A の出番です。

## A. ファイルを渡す（それぞれが自分の秘書を持つ）

**リンクではなく** `app/index.html` を渡して、
**相手が自分のClaudeアカウントで、自分のページとして公開する**やり方です。

### 渡すもの

| 渡す | 渡さない |
|---|---|
| `app/index.html`（これ1つでアプリ全部） | **書き出したJSON（`hitohi-*.json`）** |
| `docs/はじめかた.md`（使い方） | あなたの予定・会話・「わたしのこと」 |
| 開発も手伝ってもらうなら `CLAUDE.md` と `docs/` と `tests/` | |

**`app/index.html` に生活データは入っていません。** コードだけです。

### 相手にやってもらうこと

1. `app/index.html` を受け取る（メール・USB・GitHubなど、何でも）
2. 自分のClaudeアカウントで Claude Code を開く
3. こう頼む

```
この app/index.html を、私のアーティファクトとして公開してください。
capability は {"db": {}, "sample": {}, "downloads": true} の3つ。
favicon は 🧭。タイトルはファイルの中の <title> を使ってください。
```

4. 出てきたURLを、自分のホーム画面に置く（Android: Chromeで開く →「⋮」→「ホーム画面に追加」）

これで相手の秘書が立ち上がります。**中身は空の状態から始まります。**

### こうなります

| | あなた | 友達 |
|---|---|---|
| URL | 別々 | 別々 |
| 記録（予定・会話・わたしのこと） | **完全に分かれる** | **完全に分かれる** |
| AIの利用枠 | 自分のClaudeの枠 | **その人のClaudeの枠** |
| 費用 | 追加なし | **追加なし** |

**AIの枠は元々「見ている人のもの」です。** あなたの枠が減ることはありません。

### そのあと

- **更新は自動では伝わりません。** あなたが直しても、相手のページは古いままです。
  新しい `app/index.html` を渡して、相手に公開し直してもらってください。
- **相手の記録は、あなたからは一切見えません。** 逆も同じです。
- 相手が使い方に迷ったら `docs/はじめかた.md` を見てもらってください。

## 一緒に開発する場合

GitHub（`hayayumaipi-star/personal-ai`・**非公開**）に招待するのがいちばん早いです。
そのときは `CLAUDE.md` の「別の場所で続けるとき」を必ず読んでもらってください
（`git pull` から始める・テストが通った状態だけコミットする・公開まで通す）。

**ただし、公開先の Artifact URL は各自のものにすること。** `CLAUDE.md` に書いてある
再公開先はあなたのページなので、そこへ公開されると**あなたのアプリが上書きされます。**
