# 友達に渡す（それぞれが自分の秘書を持つ）

**リンクを渡すのではありません。** `app/index.html` を渡して、
**相手が自分のClaudeアカウントで、自分のページとして公開する**やり方です。

## なぜリンクを渡さないのか

記録は `notes/` `items/` `turns/` `docs/` という **共有の場所** に入っています。
保存先の仕様には、こう書かれています。

> 既定では、**どの閲覧者も共有文書を読み書きする**。

つまり **相手に保存先が渡る開き方をされると、あなたの予定・会話がそのまま見え、書き込まれます。**

2026-09-12 に別の人へ開いてもらったとき、相手の画面は空でした。当時それを
「記録は人ごとに分かれる」と書きましたが、**読み違いの可能性が高い**と分かりました
（2026-09-13）。保存先が渡らなければ localStorage だけで動くので、**まっさらな画面が出ます**。
分かれていたのではなく、**繋がっていなかった**だけ、と読むほうが仕様と整合します。

確かめきれていないので、**危ないほうに倒します。リンクは渡しません。**

なお `db` を宣言したページは仕様上「組織内部のもので、公開共有はできない」ので、
**1つのページを組織の外の人に使わせる道は、そもそもありません。**

## 渡すもの

| 渡す | 渡さない |
|---|---|
| `app/index.html`（これ1つでアプリ全部） | **書き出したJSON（`hitohi-*.json`）** |
| `docs/はじめかた.md`（使い方） | あなたの予定・会話・「わたしのこと」 |
| 開発も手伝ってもらうなら `CLAUDE.md` と `docs/` と `tests/` | |

**`app/index.html` に生活データは入っていません。** コードだけです。

## 相手にやってもらうこと

1. `app/index.html` を受け取る（メール・USB・GitHubなど、何でも）
2. 自分のClaudeアカウントで Claude Code を開く
3. こう頼む

```
この app/index.html を、私のアーティファクトとして公開してください。
capability は {"db": {}, "sample": {}, "downloads": true} の3つ。
favicon は 🧭。タイトルはファイルの中の <title> を使ってください。
```

4. 出てきたURLを、自分のホーム画面に置く（Android: Chromeで開く →「⋮」→「ホーム画面に追加」）

これで相手の秘書が立ち上がります。**中身は空の状態から始まります。**

## こうなります

| | あなた | 友達 |
|---|---|---|
| URL | 別々 | 別々 |
| 記録（予定・会話・わたしのこと） | **完全に分かれる** | **完全に分かれる** |
| AIの利用枠 | 自分のClaudeの枠 | **その人のClaudeの枠** |
| 費用 | 追加なし | **追加なし** |

**AIの枠は元々「見ている人のもの」です。** あなたの枠が減ることはありません。

## そのあと

- **更新は自動では伝わりません。** あなたが直しても、相手のページは古いままです。
  新しい `app/index.html` を渡して、相手に公開し直してもらってください。
- **相手の記録は、あなたからは一切見えません。** 逆も同じです。
- 相手が使い方に迷ったら `docs/はじめかた.md` を見てもらってください。

## 一緒に開発する場合

GitHub（`hayayumaipi-star/personal-ai`・**非公開**）に招待するのがいちばん早いです。
そのときは `CLAUDE.md` の「別の場所で続けるとき」を必ず読んでもらってください
（`git pull` から始める・テストが通った状態だけコミットする・公開まで通す）。

**ただし、公開先の Artifact URL は各自のものにすること。** `CLAUDE.md` に書いてある
再公開先はあなたのページなので、そこへ公開されると**あなたのアプリが上書きされます。**
